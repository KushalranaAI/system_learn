# Content

Original, openly licensed lessons for learning backend system design from zero
(CC BY-SA 4.0).

- [curriculum.md](curriculum.md) is the full syllabus: 3 parts, 19 modules,
  and a hands-on exercise in every lesson.
- One folder per module. Each lesson is a Markdown file with front-matter
  (`module`, `lesson`, `title`, `minutes`, optional `type: lab`).

## Lesson format

1. A hook: a real problem a growing app runs into.
2. The idea that solves it, with tables and diagrams.
3. **Try it**: an exercise, with the answer in a collapsible `<details>` block.
4. **Key takeaways**.

## Contributing

New lessons and labs are welcome. Keep them original. It's fine to learn from
other courses, but write in your own words and with your own examples.
